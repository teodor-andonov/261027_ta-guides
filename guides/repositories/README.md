# Repository guides

Personal conventions for building and documenting projects with agents.

- [Agent project memory](agent-project-memory.md) — persistent logs, decisions, visuals, naming and handoffs.
- [GitHub development and publishing](../publishing/github-development-and-publishing.md) — side branches, approved squash merges, and GitHub Actions releases (automatic on `main` or manual).
- [Copyable repository kit](../../templates/repository/) — `AGENTS.md`, `logs/` and `.gitignore` templates.

These are useful defaults rather than universal requirements. Do not manufacture old history or claim tests were run when they were not.

Runtime/browser requirements live in the separate [TA PWA guide](../pwa/README.md). Release operations live under [Publishing](../publishing/README.md).
