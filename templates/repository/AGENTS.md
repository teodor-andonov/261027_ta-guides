# Agent instructions

Treat `logs/` as persistent project memory. Read `logs/README.md`, `logs/status.md`, and `logs/roadmap.md` before work; consult relevant prior records and verify implementation against the actual code.

During work, preserve meaningful discussion, decisions, findings, progress, and evidence. Update the status and roadmap as work changes. For every user prompt involving visual work, capture and save at least one screenshot of the actual rendered state, as specified in `logs/README.md`.

Use timestamped names for new records/assets. Keep test-generated files under `test-artifacts/`, never a vague `outputs/`. Leave concise handoff notes at the end of work.
